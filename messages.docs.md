# Документация кастомных IM методов (im.*)

Базовый URL: `http://localhost:8080/method/im.methodName?key={access_token}`  
Все эндпоинты требуют авторизации по сессионному ключу (`key` или заголовок `Authorization: Bearer <key>`).

---

## Иерархия ролей в беседах

В системе групповых бесед (`peer_id > 2000000000` / `c{id}`) поддерживается трехуровневая модель прав:
1. **Создатель (Owner / Admin)**: пользователь, чей ID совпадает с `Conversation.OwnerID`.
   - Имеет исключительные права на управление составом модераторов.
   - Не может быть исключен из беседы другими участниками.
2. **Модератор (Moderator)**: участник с флагом `is_admin = true`, не являющийся создателем беседы (`user_id != *conv.OwnerID`).
   - Имеет права на изменение названия и фото чата, закрепление/открепление сообщений, получение ссылки-приглашения, исключение рядовых участников.
   - **Ограничения:** не может назначать или снимать других модераторов, не может исключать создателя беседы или других модераторов.
3. **Рядовой участник (Member)**: участник с `is_admin = false`.

---

## Методы управления модераторами

### `im.setChatModerator`
Назначает участника беседы модератором (устанавливает `is_admin = true`).

> **Доступ:** Только создатель беседы (`conv.OwnerID == currentUserID`).

#### Параметры:
| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `peer_id` | `int64` | Да* | Идентификатор беседы (`2000000000 + chat_id`) |
| `chat_id` | `int64` | Да* | Идентификатор беседы в старом формате |
| `user_id` | `int64` | Да | Идентификатор пользователя, назначаемого модератором |

*\* Должен быть передан либо `peer_id`, либо `chat_id`.*

#### Ответ:
```json
{
  "response": 1
}
```

#### Сервисное сообщение и Long Poll:
- Создается служебное сообщение с `action: "chat_moderator_add"`, `action_mid: user_id`.
- Отправляется Long Poll событие `new_msg` с `source: "chat_moderator_add"` и событие `chat_something_changed`.

---

### `im.removeChatModerator`
Снимает полномочия модератора с участника беседы (устанавливает `is_admin = false`).

> **Доступ:** Только создатель беседы (`conv.OwnerID == currentUserID`).

#### Параметры:
| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `peer_id` | `int64` | Да* | Идентификатор беседы (`2000000000 + chat_id`) |
| `chat_id` | `int64` | Да* | Идентификатор беседы в старом формате |
| `user_id` | `int64` | Да | Идентификатор пользователя, с которого снимаются полномочия |

#### Ответ:
```json
{
  "response": 1
}
```

#### Сервисное сообщение и Long Poll:
- Создается служебное сообщение с `action: "chat_moderator_remove"`, `action_mid: user_id`.
- Отправляется Long Poll событие `new_msg` с `source: "chat_moderator_remove"` и событие `chat_something_changed`.

---

### `im.getChatModerators`
Возвращает идентификатор создателя беседы и список ID всех действующих модераторов.

> **Доступ:** Любой активный участник беседы.

#### Параметры:
| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `peer_id` | `int64` | Да* | Идентификатор беседы (`2000000000 + chat_id`) |
| `chat_id` | `int64` | Да* | Идентификатор беседы в старом формате |

#### Ответ:
```json
{
  "response": {
    "owner_id": 1,
    "count": 2,
    "items": [2, 3],
    "moderator_ids": [2, 3]
  }
}
```

## Изменения в стандартных методах

### `messages.getConversationMembers`
В массив `items` возвращаются дополнительные флаги роли:
```json
{
  "response": {
    "count": 3,
    "items": [
      {
        "member_id": 1,
        "invited_by": 1,
        "join_date": 1710000000,
        "is_admin": true,
        "is_owner": true
      },
      {
        "member_id": 2,
        "invited_by": 1,
        "join_date": 1710000100,
        "is_admin": true,
        "is_moderator": true
      },
      {
        "member_id": 3,
        "invited_by": 2,
        "join_date": 1710000200
      }
    ]
  }
}
```
- `is_admin`: возвращается как для создателя, так и для модераторов (для совместимости с официальными/старыми клиентами VK).
- `is_owner`: возвращается **только** для создателя беседы (`true`).
- `is_moderator`: возвращается для назначенных модераторов (`true`).

### `messages.removeChatUser`
- Запрещено исключение создателя беседы кем-либо.
- Модераторам запрещено исключать создателя и других модераторов.
- При выходе или исключении модератора из беседы статус `is_admin` автоматически сбрасывается в `false`.
